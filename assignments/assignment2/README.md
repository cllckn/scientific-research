## Assignment 2: Comparative Evaluation of Machine Learning Algorithms Using the Iris Dataset

---

## 1. Scenario

This case study investigates the performance of two supervised machine learning classification algorithms:

- **Logistic Regression (LR)**
- **Artificial Neural Network (ANN)**

The evaluation is conducted using the **Iris dataset**, a well-known benchmark dataset for multi-class classification problems.

Both models are trained and tested under identical experimental conditions to ensure fairness. The objective is to 
analyze and compare their performance using standard classification metrics and to understand their strengths and 
limitations in a controlled setting.

---

## 2. Objectives

- Apply and implement **Logistic Regression** and **ANN**
- Perform **model training, evaluation, and comparison**
- Analyze results using **quantitative performance metrics**
- Interpret **confusion matrices and classification reports**
- Present findings in a **scientific article format using LaTeX**

---

## 3. Requirements

Students are expected to:

### 3.1 Data Preparation
- Use the **Iris dataset**
- Split the dataset into:
  - Training set (e.g., 70–80%)
  - Test set (e.g., 20–30%)
- Apply preprocessing if necessary (e.g., normalization for ANN)

---

### 3.2 Model Implementation

#### Logistic Regression
- Train a Logistic Regression classifier
- Use default or justified hyperparameters

#### Artificial Neural Network (ANN)
- Implement a simple feedforward neural network:
  - Input layer (features)
  - At least one hidden layer
  - Output layer (3 classes)
- Configure:
  - Activation functions (e.g., ReLU, Softmax)
  - Optimizer (e.g., Adam)
  - Loss function (categorical cross-entropy)

---

### 3.3 Performance Evaluation

Evaluate both models using:

- **Accuracy**
- **Precision**
- **Recall**
- **F1-score**
- **Confusion Matrix**

Optional:
- Training time


---

### 3.4 Comparative Analysis

- Compare LR and ANN results
- Identify:
  - Best performing model
  - Strengths and weaknesses
- Provide interpretation based on:
  - Metrics
  - Confusion matrices
